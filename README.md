# Movie Reservation System

A single-cinema booking app: browse showtimes by date, pick numbered seats, hold
them, confirm the booking and manage bookings in "My reservations". The user app
is `frontend/` (React + TypeScript + Vite) and talks to the API in `backend/`
(FastAPI + PostgreSQL).
